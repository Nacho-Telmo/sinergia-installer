# Repositorios activos de serie en /etc/pacman.conf:

[chaotic-aur]
Include = /etc/pacman.d/chaotic-mirrorlist

[sinergia-repo]
SigLevel = Optional TrustAll
Server = https://nachotelmo.github.io/sinergia-repo/$arch

Junto con los repositorios oficiales de Arch (core y extra), tanto [chaotic-aur] como [sinergia-repo] vienen listos de fábrica.

Arquitectura del sistema

Base Arch Linux Pura con Chaotic-AUR listo desde el primer inicio

Sin capas innecesarias ni bloqueos: mantenés acceso directo a los repositorios oficiales de Arch Linux, paquetes precompilados de Chaotic-AUR y nuestro repositorio propio mantenido por la comunidad.

Base Arch Linux Pura + Chaotic-AUR

Sistema base Arch Linux con pacman nativo e integración de serie con el repositorio Chaotic-AUR para instalar miles de paquetes del AUR ya compilados sin esperar compilaciones locales.

KDE Plasma 6 (Wayland)

Escritorio moderno, fluido y personalizable con sesión Wayland por defecto, gestor de inicio SDDM tematizado y persistencia visual completa tras instalar.

Instalador Arkea

Construido sobre archiso con el instalador gráfico Arkea (sinergia-installer) para un particionado asistido o manual y soporte UEFI/BIOS.

Repositorio Firmado GPG

Incluye sinergia-repo y sinergia-keyring preinstalados para recibir actualizaciones directas de todas las aplicaciones propias vía pacman -Syu.

sinergia-store Preinstalada

Tienda de aplicaciones unificada para explorar e instalar paquetes oficiales, AUR, Flatpak y todas las utilidades opcionales de Sinergia.

sinergia-welcome Preinstalada
